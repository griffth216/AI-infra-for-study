大二正是切入 AI Infra 的黄金时间！能够从应对一次课题组汇报，转化为系统性学习的动力，这个思维转变非常棒。

AI Infra（人工智能底层架构）是一个典型的“交叉学科”，它要求你既要懂“天上飞的算法”（模型结构），又要懂“地上跑的硬件”（GPU与内存）。之前突击了解的 FlashAttention、内存墙、算子优化其实属于非常靠后的高阶内容，现在我们需要把缺失的地基一层层补齐。

为你定制的 0 基础到入门的 AI Infra 学习路线图，分为四个核心阶段：

### 阶段一：筑牢底层地基（CS 核心基础）

_大二的重点是不要急于写算子，先把计算机系统的运转逻辑搞透。_

- **C/C++ 进阶：** 这是 Infra 领域的母语。需要熟练掌握指针、内存管理、面向对象和标准模板库（STL）。
    
- **计算机体系结构：** 重点理解 CPU/GPU 架构区别、内存层级（寄存器、SRAM、HBM 的运作机制）、缓存一致性。
    
- **操作系统：** 深入理解进程与线程、并发控制、虚拟内存与分页机制（这就对应了 PagedAttention 的底层逻辑）。
    
- _推荐资源：_ CMU 15-213 (深入理解计算机系统 CSAPP)。
    

### 阶段二：掌握上层负载（深度学习基础）

_你需要知道你要优化的目标（大模型）到底长什么样。_

- **深度学习原理：** 前向传播、反向传播与链式法则。
    
- **PyTorch 框架实践：** 不要只停留在调包，要理解 PyTorch 底层的 Tensor 结构、Autograd（自动求导）机制、动态计算图。
    
- **Transformer 架构剖析：** 抛开高阶优化，尝试手写一个最基础的自注意力机制，彻底吃透 $Q \times K^T \times V$ 和 GEMM 的全流程。
    
- _推荐资源：_ 李宏毅《深度学习》、Andrej Karpathy 的 Neural Networks: Zero to Hero 系列视频。
    

### 阶段三：掌握核心武器（并行计算与 CUDA 编程）

_这是 AI Infra 工程师的真正看家本领，也是跨越 0 基础的分水岭。_

- **并行计算思维：** 理解线程块（Block）、网格（Grid）、线程束（Warp）的物理对应关系。
    
- **CUDA 编程实践：** 从写第一个 `hello_world.cu` 开始，到实现向量加法，再到手写一个基础版的矩阵乘法（GEMM）。
    
- **初阶性能优化：** 学习共享内存（Shared Memory，即代码层面的 SRAM 调用）、内存合并访问（Coalesced Memory Access）、以及分块（Tiling）技术。
    
- _推荐资源：_ 《CUDA C 编程权威指南》、NVIDIA 官方的 CUDA 教程、CMU 15-418 (并行计算机体系结构与编程)。
    

### 阶段四：触达工业前沿（推理加速与系统级优化）

_有了前面的基础，再看顶会论文和前沿技术就能游刃有余了。_

- **推理框架系统：** 了解 vLLM、TensorRT 等工业级推理引擎的运转逻辑。
    
- **显存管理技术：** KV Cache 调度优化、Page/Radix Attention。
    
- **高阶编译器与新生态：** 了解 Triton（OpenAI 推出的简化版 GPU 编程语言，极大降低了手写高阶算子的门槛）、算子融合（Kernel Fusion）的具体实现。
